# OTG-Printer

A USB On-The-Go (OTG) printer application that enables direct printing to USB printers from Android devices.

## Overview

OTG-Printer allows Android devices with USB OTG support to connect and print directly to USB printers without requiring a network connection or additional drivers. This application provides a convenient way to print documents, images, and other content using the USB OTG protocol.

## Features

- **Direct USB Printing**: Connect USB printers directly to your Android device via OTG cable
- **No Network Required**: Print without WiFi or internet connectivity
- **Multiple Format Support**: Print various document types and images
- **Easy to Use**: Simple and intuitive interface for quick printing
- **Printer Detection**: Automatic detection of connected USB printers

## Requirements

- Android device with USB OTG support
- USB OTG cable or adapter
- Compatible USB printer
- Android 5.0 (Lollipop) or higher

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Jerusha99/OTG-Printer.git
   ```

2. Open the project in Android Studio

3. Build and run the application on your Android device

## Usage

1. Connect your USB printer to your Android device using an OTG cable
2. Launch the OTG-Printer application
3. Grant USB permissions when prompted
4. Select the document or image you want to print
5. Configure print settings (copies, orientation, etc.)
6. Tap the "Print" button

## Supported Printers

The application aims to support most standard USB printers that comply with the USB printing class specifications. Compatibility may vary depending on the printer model.
